# Portfólio — Pedro Bonis

Next.js 15 + TypeScript + Tailwind CSS v4. Deploy no Vercel.
Repo: https://github.com/Bonisph/bonis-portfolio

## Stack
- Framework: Next.js 15 (App Router)
- Linguagem: TypeScript
- Estilização: Tailwind CSS v4 com dark mode via `@custom-variant`
- Contextos: `LanguageContext` (PT/EN/ES) e `ThemeContext` (light/dark)
- Dados: `src/data/portfolio.ts` — editar aqui para atualizar conteúdo
